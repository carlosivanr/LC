This directory contains raw and label data export from RedCap Project ID 33298
for the AHRQ Long COVID Longitudinal Patient Surveys.

Only Record Id 5 is in the data. A change to the instruments needed to be made
for T5 after the participant had already submitted a T5 Survey. In order to 
make changes to the instruments, all T5 data would have been wiped out.

The following data sets contain data for this individual to later merge
into the updated T5 instrument. Some fields will match and will be 
merged while others will not be able to be merged.
